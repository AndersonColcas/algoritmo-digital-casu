# Casu - Algoritmo Digital

## Agencia de Marketing Digital para TikTok

Casu es una plataforma profesional desarrollada por **Algoritmo Digital** que utiliza la API oficial de TikTok para proporcionar métricas avanzadas y servicios de marketing digital para empresas y creadores.

### Características

- 📊 **Métricas en Tiempo Real**: Análisis detallados de tus campañas y contenido en TikTok
- 🎯 **Marketing Estratégico**: Optimización de estrategias basadas en datos reales
- 📈 **Reportes Profesionales**: Informes completos sobre el rendimiento de tu contenido

### GitHub Pages

Este sitio está diseñado para ser publicado en GitHub Pages y cumple con todos los requisitos legales necesarios para:

- Uso de la API de TikTok
- Cumplimiento GDPR/RGPD
- Protección de datos (CCPA)
- Términos y Condiciones completos
- Política de Privacidad detallada

### Estructura del Proyecto

```
├── index.html          # Página principal
├── terms.html          # Términos y Condiciones
├── privacy.html        # Política de Privacidad
├── styles.css          # Estilos CSS
└── README.md           # Este archivo
```

### Publicar en GitHub Pages

1. Sube los archivos a tu repositorio de GitHub
2. Ve a Settings → Pages
3. Selecciona la rama principal como source
4. Tu sitio estará disponible en: `https://tu-usuario.github.io/algoritmo-digital-casu/`
